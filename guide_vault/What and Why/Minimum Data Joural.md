# Details

It occurs to me that most of this site explains how my **admittedly over-the-top** Data Journal works. You genuinely don't need all the things I do. I like having them, but there's **huge value** in the simplest imaginable Data Journal.

> [!Success] All you need
> A spreadsheet with:
> - Column A: **Date**
> - Column B: **Journal Entry**

That's it.

If you *want* to add more columns to track other things - that's easy and works well, but is not required!

## How to Make a Minimal Data Journal

*Any* of the following would work great.

- A [Google Sheet](https://docs.google.com/spreadsheets/u/0/) with 2 columns open in a pinned tab on your browser.
- An Excel spreadsheet saved on your desktop
- A database in [Notion](https://www.notion.com)
- A [Google Form](https://docs.google.com/forms/u/0/) you fill out each night ← I did this for **5 years**, it works great

The easier you can make entry, and the more noticeable you can make days where you forgot to put anything in, the better. I put in "yesterday data" all the time. No worries.

There's no wrong way to eat this Reece's.
